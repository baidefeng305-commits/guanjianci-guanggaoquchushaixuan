# 广告关键词去除筛选

## 输入与报表理解

产品名称、卖点及广告报表是主要输入。可接受CPA、目标ROAS、广告前单件利润、报表日期和调整历史属于进一步判断所需信息，不是开始分析的强制门槛。

先检查计划、广告组、广告商品、投放属性/商品ID、版位、关键词及指标列。不要硬编码列号或假定只有一种导出格式；接受完整报表或简化的关键词汇总表：

- 完整报表：优先使用14天口径（用户指定其他窗口则从其要求），总/直接/间接口径分开。全部指标保持同一窗口。
- 简化表只有总订单及ROAS：照实使用，不编造直接/间接拆分或缺失销售额。
- 缺少销售/订单列，指出无法判断回报或成交，只做相关性和可用指标筛查。
- 混有其他产品/计划时先隔离本产品；无法可靠归属的行不强行纳入关键词判断，明确范围限制。
- 活动开始日不是报表统计开始日；没有逐日起止日及调整历史，不能确认“长期”、趋势、调整无效或归因成熟度。

## 分版位与聚合

1. 仅实际搜索词进入否定词候选。空关键词、非搜索、站外流量单列版位分析，不填造搜索词。
2. 广告明细的汇总键至少保留计划、广告组、版位和规范化关键词。不同产品不合并；同产品规格在分析上汇总时保留SKU/来源，提醒执行前核对差异。不要以合并结果跨计划一键否定。
3. 同词重复行可能是不同投放SKU或转化商品拆分。确认曝光/点击/花费是否可加、是否存在被重复展开的非加总指标；无法确认就提示可能重复，不机械加总。
4. 订单、销售额按可加行粒度汇总。直接+间接应与总口径对账；不同口径不相加。说明是归因报表统计，不声称是去重顾客/订单数。
5. 保留零花费有单、有销售额以及零花费有点击的行；免费点击多不是高花费浪费。

## 五项优化标准

### 1. 产品明显不相关

针对不同品类、形态、明确不兼容对象或已确认不符的规格，建议按完整搜索词精准否定，写明不匹配点。

未提到功能不等于不支持；用户确认的功能不再反复核实。竞品品牌不自动等于无关。适配产品的品牌/型号词不得仅按品牌删除。

### 2. 高点击、长期零订单

先降价、限额观察；成熟归因下持续零单且调整后仍无改善，再考虑暂停、精准否定或去除。

如需初筛数值，可使用“累计点击≥10且零订单”的可配置工作阈值，明确它只是本次初筛，不是用户图片规定的数值或行业标准；用户有自定门槛时优先使用。不能用累计点击替代长期性证据。

核心相关词优先控费排查，不直接永久否定。检查近似写法/同义变体是否已出单，提示避免词组或广泛否定误伤。

### 3. 高花费、零订单

用用户可接受单笔广告获客成本CPA作对比；超出后优先降价、暂停或评估否定。

未提供CPA时写“缺少可接受CPA，暂不能判定超成本”；不要使用任意固定花费/CPC作为盈亏线。少量点击但CPC异常可单列出价排查，但不能证明关键词不相关或无效。若用相对CPC异常门槛，标明实际计算方法及其只用于排查。

### 4. ROAS长期低于目标

需要目标ROAS、足够订单/点击、成熟归因和历史调整证据。多次优化仍低于目标，才进一步建议控制流量、暂停等。

缺少任一关键证据时说明限制；不能因只出1单或ROAS数值较低就直接否定，不能把ROAS当利润率。已成交词优先保护，但不意味着已盈利或应提高出价。

### 5. 点击少、零订单

1—3次点击通常继续积累，不宜判断无效；4—9次也可限额观察，不强行当高点击长期无效。若产品意图明显不符，仍可依据标准1否定，不需花钱积累更多样本。

## 指标计算与不完整数据

- CTR = 合计点击 / 合计展示。
- CPC = 合计花费 / 合计点击。
- ROAS = 合计实际转化销售额 / 合计花费。直接ROAS用直接销售额作分子，不能用总销售额冒充直接回报。
- 不简单平均原行CTR、CPC、ROAS；分母为0时用无法计算等明确状态，不造出健康的0或无限值。
- 原表ROAS可能是倍率、百分比数或百分比字符串，先核对原格式及销售额/花费。统一后写明例如“倍”或“%”，不盲目再乘/除100。
- 没有销售额时优先保留原行ROAS。只有单位和行粒度明确、各行可追溯时才可按花费×倍率估算并标“推算”；不能当作已核实销售额。
- 零花费但有订单而没有销售额的组，ROAS不完整，不能因0×原ROAS而丢掉转化后声称完整回报。
- 缺失值不是0。全表零转化时先提示核对导出筛选、产品ID、归因和售卖状态，不把所有词一刀切删掉。

## 输出建议及理由

按实际情况使用这些类别，不为凑齐类别建立空清单：

- 建议精准否定：明确不匹配，有具体语义证据。
- 高点击零单先控费：先降价观察，不等同直接否定。
- 有直接成交先保留：进一步核对盈利目标。
- 仅间接成交待评估：不能当成本SKU直接成交，也不能说完全零成交。
- 核实后再决定：明确列出所缺的信息。
- 继续积累数据：低样本或证据不足。

优先按处理紧迫性分组，同组可按花费降序。保留全部有效关键词以及已成交/观察词，不只给否定名单而丢失分析依据。

基础字段：

`处理建议 | 原文关键词 | 中文翻译 | 意图相关性 | 展示 | 点击 | 广告费 | CPC | 订单 | 销售额 | ROAS | 原因 | 执行备注 | 来源行`

有直接/间接列时分别展示；存在多个计划/SKU时加定位信息。说明原单位、归因窗口、来源、初筛门槛、缺失目标和未成熟归因风险。

## 待核实必须给出具体问题

不要只写“待核实”。按词或问题组列出已确认依据、尚缺信息、要问用户的问题和确认后的处理：

| 疑问 | 应询问的信息 | 后续方向 |
| --- | --- | --- |
| 24小时录像 | 连续录像时长、外接供电、循环录像与存储条件 | 支持则保留按数据观察；不支持则评估完整词否定 |
| 防水/水下 | 防水深度、时长、裸机或配壳、海水条件 | 防水已确认不再问是否防水，仅核对额外条件 |
| 安装/佩戴 | 是否含挂颈、头盔、宠物项圈等对应支架，负载及使用要求 | 磁吸/背夹已确认不等于支持所有专用支架 |
| 功能/型号/容量 | 兼容机型、真实容量、规格、其他型号是否可分流 | 不符时仅针对当前SKU，不跨型号否定 |
| 原厂/正品/竞品名称 | 自有品牌与供货型号、是否原厂、是否计划做竞品获客 | 不推断品牌授权，不统一删除竞品词 |
| 高花费 | 可接受CPA，或售价与扣平台/履约等费用后的广告前贡献 | 对比后控费，不把成本、利润和广告费混用 |
| 低ROAS/长期零单 | 目标ROAS、统计区间、逐日及之前出价/暂停调整记录 | 数据成熟、证据充分后再判断长期无效 |

先完成可判断部分，汇总最少但具体的问题，不因少量缺失而搁置全部分析。用户补充卖点后只消除被证据覆盖的疑问；竞品策略、CPA及目标ROAS不靠卖点自动确认。

## 交付核验

核对搜索/非搜索花费不混、原始记录未被删除或重复加总、直接/间接拆分及汇总一致、零费转化保留、每词有中文和理由、观察词未误写成否定词、近似成交词得到保护。历史候选词花费不是未来可节省金额；最终不得声称已在Coupang实施调整。
